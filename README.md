# Программа для вычисления факториала

## Описание
Программа запрашивает у пользователя положительное целое число и вычисляет его факториал с обработкой ошибок и оптимизацией для больших чисел.

## Функциональность
- Ввод и валидация пользовательских данных
- Вычисление факториала с использованием библиотеки math
- Обработка ошибок (нечисловые данные, отрицательные числа)
- Оптимизация для работы с большими числами

## Требования
- Python 3.6+
- Стандартная библиотека math

## Запуск
```bash
python factorial_calculator.py
